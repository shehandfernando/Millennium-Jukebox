# 💽 Millennium Jukebox

![Millennium Jukebox Interface Preview](./Img-3.png)

**Millennium Jukebox** is a fully functional, retrofuturistic web audio player that captures the "Digital Maximalism" and "Blobject" aesthetics of the late '90s and early 2000s. Inspired by iconic software like Winamp and the design language of the original iMac G3, it blends turn-of-the-century tech optimism with a modern React engine.

### ✨ Key Features

* **Local File Playback:** Load your own `.mp3` files directly into the playlist using the "Eject/Load" button.
* **Internet Radio Dial:** Stream trending tracks by genre via the decentralized **Audius API**.
* **Active Audio Visualizer:** Real-time green EQ bars that react to your music using the Web Audio API.
* **Custom Hardware Skins:** Instantly toggle between the classic **"Liquid Metal"** look and a dark **"Neon Cyber"** theme.
* **Authentic Controls:** Features a physical-looking track scrubber, a chunky metallic volume slider, and a digital time counter tracking elapsed and total duration.

### 🛠️ Tech Stack

* **Core:** React + Vite
* **Audio Engine:** Native HTML5 Audio API + Web Audio API for visualization.
* **Styling:** Advanced CSS utilizing complex gradients and `inset` box-shadows to recreate 3D plastic and metal textures.

### 🚀 Getting Started

1.  **Clone the Repo:**
    ```bash
    git clone [https://github.com/shehandfernando/Millennium-Jukebox.git](https://github.com/shehandfernando/Millennium-Jukebox.git)
    ```
2.  **Install Dependencies:**
    ```bash
    npm install
    ```
3.  **Launch:**
    ```bash
    npm run dev
    ```
4.  **View:** Open `http://localhost:5173` in your browser.
